## Comparison
| Area                       | Spring JDBC             | Spring Data JPA                              |
| -------------------------- | ----------------------- | -------------------------------------------- |
| SQL                        | Written explicitly      | Usually generated by Hibernate               |
| Mapping                    | Manual row mapping      | Entity mapping                               |
| Relationships              | Managed manually        | `@OneToMany`, `@ManyToOne`                   |
| Insert children            | Explicit inserts        | Cascade can insert automatically             |
| Complex SQL                | Straightforward         | May require JPQL/native SQL                  |
| Database-specific features | Easy to use             | Sometimes awkward                            |
| N+1 issue                  | Fully controlled by SQL | Must understand lazy loading and fetch joins |
| Performance visibility     | High                    | Requires Hibernate knowledge                 |
| Boilerplate                | More repository code    | Less CRUD code                               |
| Domain model               | Simple records/POJOs    | Persistence-aware entities                   |
| Bulk processing            | Strong with batch SQL   | Possible, but persistence context needs care |
| Best fit                   | SQL-heavy services      | Domain-oriented CRUD applications            |


## Practical recommendation
* Spring JDBC
    * Use when you want to have full control over SQL queries and database interactions
    * Suitable for simple applications or when performance is critical
    * Requires more boilerplate code for CRUD operations
* Spring Data JPA
    * Use when you want to leverage the power of ORM and reduce boilerplate code
    * Suitable for complex applications with relationships and entity management
    * Provides built-in support for pagination, sorting, and query derivation

Note:
```
Order command/write operations → Spring Data JPA
Complex reports and dashboards → Spring JDBC
```
